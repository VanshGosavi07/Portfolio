# Vansh Gosavi - Portfolio Website

A modern, responsive portfolio website built with Flask and Tailwind CSS, showcasing my skills, projects, education, and experience as a Computer Science student.

## 🚀 Features

- **Responsive Design**: Mobile-first design that works on all devices
- **Modern UI**: Clean and professional interface using Tailwind CSS
- **Modular Structure**: Separate HTML files for each section
- **Contact Form**: Functional contact form with validation
- **Smooth Animations**: Subtle animations and transitions
- **SEO Friendly**: Optimized for search engines

## 🚀 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd Portfolio
   ```

2. **Create a virtual environment** (recommended)
   ```bash
   python -m venv portfolio_env
   
   # On Windows
   portfolio_env\Scripts\activate
   
   # On macOS/Linux
   source portfolio_env/bin/activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application**
   ```bash
   python app.py
   ```

5. **Open your browser**
   Navigate to `http://localhost:5000` to view the portfolio

## 🎨 Customization

### Personal Information
Update the following files with your personal information:

- **Hero Section**: `templates/sections/hero.html`
- **About Section**: `templates/sections/about.html`
- **Education**: `templates/sections/education.html`
- **Contact Info**: `templates/sections/contact.html`
- **Footer**: `templates/sections/footer.html`

### Skills & Technologies
Modify `templates/sections/skills.html` to reflect your technical skills and proficiency levels.

### Projects
Update `templates/sections/projects.html` with your actual projects, including:
- Project descriptions
- Technologies used
- Live demo links
- GitHub repository links

### Styling
The project uses Tailwind CSS for styling. You can customize:
- Colors by modifying the color classes
- Spacing and layout
- Animations and transitions

## 📱 Responsive Design

The portfolio is fully responsive and tested on:
- Desktop (1024px+)
- Tablet (768px - 1023px)  
- Mobile (320px - 767px)
